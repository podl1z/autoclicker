# AutoClicker

Простой автокликер для Windows с окном и глобальной горячей клавишей.

## Возможности

- Интервал между кликами: часы / минуты / секунды / миллисекунды (минимум 1 мс)
- Кнопка мыши: левая, правая, средняя
- Одинарный или двойной клик
- Клик в текущей позиции курсора
- Клик по картинке: программа сама находит на экране выбранную кнопку (например «Следующая страница») и кликает по ней
- Старт/стоп кнопками в окне или клавишей **F6** — работает, даже когда окно свёрнуто или не в фокусе
- Счётчик кликов

## Клик по картинке

1. Откройте окно, где есть нужная кнопка.
2. В AutoClicker нажмите **«Выбрать кнопку на экране…»**. Окно спрячется; обведите кнопку мышкой (Esc — отмена).
   Образец сохраняется в `%APPDATA%\AutoClicker\template.png` и подхватывается при следующем запуске.
3. Режим «По картинке» включится сам. Нажмите **Старт** или **F6**.

Программа с заданным интервалом ищет кнопку, переводит на неё курсор и кликает. Если кнопки не видно дольше,
чем указано в поле «Стоп, если не видно, сек» (по умолчанию 5), — кликер останавливается сам.

Поиск идёт по точному совпадению картинки, поэтому если поменялся масштаб страницы/экрана или тема оформления,
выберите кнопку заново.

## Запуск готового exe

Скачайте `AutoClicker.exe` из [Releases](https://github.com/podl1z/autoclicker/releases) и запустите.
Python ставить не нужно.

## Запуск из исходников

Нужен Python 3.10+.

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

## Сборка exe

```powershell
.\build.ps1
```

Результат — `dist\AutoClicker.exe`.

## Тесты

```powershell
.\.venv\Scripts\pip install -r requirements-dev.txt
.\.venv\Scripts\python -m pytest
```

## Известные ограничения

- Клики не доходят до окон, запущенных от имени администратора, если сам кликер запущен без прав администратора (так устроена защита Windows). В этом случае запустите AutoClicker тоже от администратора.
- Windows SmartScreen / Defender может предупреждать о неподписанном exe, собранном PyInstaller. Это ложное срабатывание; при сомнениях соберите exe сами из исходников.
